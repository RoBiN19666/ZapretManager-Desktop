# Zapret Manager 2.3.1

- Исправлено затемнение самого диалога подтверждения: окно теперь рисуется
  поверх затемнения (`Order::Foreground`), а не под ним.
- При запуске показывается окно **«Доступны обновления»**, если есть новые
  версии. В нём перечислены компоненты: Zapret Manager, zapret, TG WS Proxy —
  с текущей и новой версией.
- Уведомление показывается один раз для набора версий; «Позже» запоминает
  набор в `manager.ini` (`UpdateNoticeDismissed`), новая версия снова покажет окно.
- Проверка TG WS Proxy при старте добавлена в общий стартовый чек обновлений.
