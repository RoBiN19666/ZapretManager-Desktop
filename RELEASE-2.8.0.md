# Zapret Manager 2.8.0

- Страница «Обновление» переименована в **«Установленные версии»**.
- В одном месте показаны Zapret Manager, zapret (Flowseal) и TG WS Proxy:
  текущая версия, доступная версия и состояние.
- Кнопка **«Проверить всё»** проверяет обновления всех компонентов сразу.
- Кнопка **«Обновить всё»** устанавливает доступные обновления: zapret и
  TG WS Proxy параллельно, менеджер — последним, потому что он перезапускается.
- Убраны отдельные карточки обновлений с «Обзора» и страницы «TG-прокси»,
  чтобы версии не были разбросаны по приложению.
- Для zapret остались подробности релиза, выбор другой версии и параметры
  обновления — ниже общего списка.
