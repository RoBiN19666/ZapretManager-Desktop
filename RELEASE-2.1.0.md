# Zapret Manager 2.1.0

Полностью нативная версия на Rust: один `ZapretManager.exe` без .NET и WinForms.
Ветка `main` — актуальная Rust-версия; C#-версия больше не поддерживается.

## Новое

- **Автоподбор стратегии** на странице «Тест стратегий»: 40/120/250 вариантов
  desync-параметров вокруг выбранной базы; лучший сохраняется как `general (AUTO).bat`.
- **Отдельная страница «О программе»** с крупным логотипом, ссылками и поддержкой.
- **Тихий TG WS Proxy** из официальных исходников Flowseal + портативный Python
  (без окна и без иконки в трее).
- Одна карточка **«Папка zapret»** в настройках: указать папку, скачать с нуля, мастер.
- Мастер первой настройки закрывается после выбора существующей папки.

## Исправлено

- HTTP 302 при скачивании zapret и TG WS Proxy (WinHTTP redirect policy).
- Отсутствующие `*-user.txt` больше не роняют `winws.exe`; пустые пользовательские
  списки допустимы.
- Тест стратегий: убраны tofu-символы `✓/✗`, наложения текста, добавлена легенда.
- Иконка приложения и панели задач.
- Меню трея работает при скрытом окне.
- Снижена нагрузка на CPU: фоновый опрос процессов, оптимизирован DNS-сторож.
- Журнал DNS включается автоматически при стороже и проверке приложения.

## Установка

1. Закрыть старый Zapret Manager.
2. Заменить `ZapretManager.exe` на новый.
3. Запустить; при первом запуске откроется мастер настройки.

Требования: Windows 10/11 x64, права администратора для запуска `winws.exe` и служб.
