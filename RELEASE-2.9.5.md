# Zapret Manager 2.9.5

- Страница «Списки» больше не растягивается на высоту содержимого: редактор
  занимает область под размер окна, а длинный список прокручивается внутри
  рамки. `ipset-all.txt` (десятки тысяч строк) открывается без многоэкранной
  страницы.
- Список файлов слева тоже получил собственную прокрутку и не вылезает за
  границы окна.
- Кнопки «Сохранить», «Добавить строку», «Причесать строки» остаются на виду —
  не нужно прокручивать полстраницы, чтобы их найти.

SHA-256: см. `checksums.txt` в этом релизе.
