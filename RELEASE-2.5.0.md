# Zapret Manager 2.5.0

## Светлая тема

- Заголовок окна и рамка теперь перекрашиваются в светлые цвета при выборе
  светлой темы (DWM caption/border/text), а не остаются тёмными.
- Палитра светлой темы сделана светлее и нейтральнее.
- Всплывающие уведомления больше не используют жёстко заданный тёмный фон.

## Сторож сайтов

- Сторож теперь читает DNS-события **всех приложений**, а не только процессов
  с именем браузера. Это важно для Chrome/Edge с дочерними процессами.
- В карточке «Фоновый сторож» появился список перехваченных доменов.
- Проблемные домены подсвечиваются: «требует добавления» или
  «добавлен автоматически».
- Кнопка **«Добавить найденные»** добавляет проблемные домены в список.
- Кнопка «Очистить список» убирает накопленные записи.
- При включении сторожа DNS-кэш сбрасывается, чтобы новые запросы точно
  попадали в журнал.
