# Zapret Manager 2.4.1

- Убрана кнопка «Включить журнал DNS»: журнал включается автоматически
  при включении сторожа и при наблюдении за приложением.
- Включение сторожа больше не показывает два уведомления. Теперь одно
  сообщение: «Сторож включён: журнал DNS включён.»; при ошибке журнала —
  одно предупреждение с причиной.
