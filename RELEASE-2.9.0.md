# Zapret Manager 2.9.0

- В «Инструментах» появилась карточка **«Удаление»**.
- Можно отдельно:
  - открыть папку zapret;
  - удалить zapret (с сохранением или удалением списков);
  - удалить TG WS Proxy;
  - очистить данные менеджера;
  - удалить всё, включая exe.
- При удалении zapret останавливаются служба и winws.exe, удаляются служба
  zapret, драйвер WinDivert и записи из hosts.
- При удалении TG WS Proxy очищаются его папка, тихий режим, данные в
  `%APPDATA%\TgWsProxy` и автозапуск.
- Полное удаление удаляет exe и папку data после закрытия приложения.
