# История версий

Все заметные изменения Zapret Manager. Новые версии — сверху, версия совпадает
с `Cargo.toml` и тегом релиза.

Установка и требования — в [README.md](README.md). Контрольные суммы — в `checksums.txt`
соответствующего релиза на GitHub.

Новая запись добавляется сюда же, отдельным разделом сверху. Отдельные файлы
`RELEASE-x.y.z.md` в корне репозитория больше не создаём.

## 2.9.7

Исправления по внешнему аудиту 2.9.6. Версия 2.9.7 — первый выпуск после него.

### Безопасность

- Самообновление не ставится без `checksums.txt`; неподписанное обновление
  отклоняется, если установленная версия подписана; проверяется отзыв сертификата.
- Тег релиза санитизируется перед использованием в путях; `--apply-update`
  принимает только `ZapretManager*.exe` вне `%SystemRoot%`.
- Запуск `winws.exe`, службы и TG WS Proxy из `%TEMP%` запрещён.
- `hosts` читается с автоопределением кодировки; ошибка чтения и отсутствие
  END-маркера больше не приводят к потере файла.
- `TgDir` проверяется перед `remove_dir_all`; blob-файлы пишутся только внутрь
  папки zapret.
- TOCTOU: XML задачи автозапуска и cleanup-`.cmd` получают уникальные имена
  и создаются через `create_new`.
- WinHTTP: запрещено понижение `https → http`, файл создаётся только после 2xx.
- Лимиты распаковки (20 000 файлов, 256 МиБ на файл, 1 ГиБ суммарно)
  и скачивания (1 ГиБ).
- `restore-uac.ps1`: значения из JSON проходят allowlist, `0` (UAC выключен)
  не восстанавливается.

### Надёжность

- Операции start/stop/restart/install/remove сериализованы; при неудачном старте
  служба удаляется (откат).
- Блок «мои добавления» официальных списков переносится в `.changes`
  до перезаписи файлов.
- Ошибка чтения списка больше не считается пустым файлом: baseline не затирается,
  редактор отказывается сохранять.
- `.zmb` пишется атомарно, включает `.changes`/`.baseline`, отвергает копии
  от более новой версии.
- `manager.ini` сохраняется с переносом только изменённых ключей.
- «Применить и проверить» сравнивает доли целей; HTTP-цель успешна только при 2xx/3xx.
- Журнал: ротация в `manager.log.1`, открытый дескриптор, устойчивость
  к отравленному мьютексу.

### Интерфейс

- Подтверждение стало модальным: клики не проходят сквозь затемнение, Esc отменяет.
- Выход с идущей операцией или несохранёнными списками спрашивает подтверждение.
- Повторный запуск операции блокируется до завершения текущей.
- «Свернуть в трей» работает только если значок действительно создан.
- Тема «как в Windows» определяется по реестру; масштаб ограничен 75–150 %.
- Мастер проверяет папку установки до скачивания архива.
- Шрифты и трей больше не падают на нестандартной конфигурации системы.

### Документация и сборка

- 34 файла `RELEASE-x.y.z.md` сведены в `CHANGELOG.md`, `docs/rust/FIXES-*.md` —
  в `docs/rust/FIXES.md`.
- `rust-version = 1.88` (фактическое требование зависимостей), README приведён к фактам.
- CI: `persist-credentials: false`, подпись обязательна, если она настроена.
- Добавлен ключ `--restore-uac`, который ранее был только в документации.

## 2.9.4

Дополнение к 2.9.3.

- **Текущие быстрые настройки запоминаются сами** — при первом запуске, без

## 2.9.3

Релиз про сохранение настроек при переустановке.

- **Быстрые настройки дублируются в `manager.ini`**: режим игрового фильтра и
  диапазоны портов, режим IP-фильтра и флаг «Авто-проверка обновлений zapret».
  Сами переключатели по-прежнему живут в папке zapret, но теперь после установки
  zapret в новую папку («с нуля») они восстанавливаются, а не сбрасываются
  в значения из архива.
- **Резервная копия `.zmb` стала полнее**: в неё входят
  `utils\check_updates.enabled` и `lists\ipset-all.txt` с `.backup`, поэтому
  режим IP-фильтра и флаг автообновления переживают восстановление копии.
- **Предупреждение о «потерянных» настройках**: если `manager.ini` остался в
  другой папке (например, exe перенесли из Program Files в обычную папку или
  наоборот), при запуске появляется уведомление с путём к старому файлу.
- Мелкие правки формулировок в уведомлениях.

Функциональность не менялась: все возможности 2.9.2 на месте.

## 2.9.2

Релиз про ложные срабатывания антивирусов и воспроизводимую сборку.

- **Манифест приложения** встроен в exe: `asInvoker`, поддерживаемые версии
  Windows, DPI-awareness (PerMonitorV2), long paths. Windows больше не
  применяет к exe эвристику «это установщик».
- **Сборка перенесена в GitHub Actions** (`.github/workflows/release.yml`):
  exe собирается на чистом раннере из тега, а не на локальной машине.
  `tools/verify-exe.ps1` в CI падает, если пропал манифест или ресурс версии.
- **Контрольная сумма** (`checksums.txt`) считается после подписи, если
  подпись включена.
- **Самообновление стало строже**: сверяются размер ассета из GitHub API,
  SHA-256 из `checksums.txt` и Authenticode-подпись файла (`WinVerifyTrust`).
  Недействительная подпись отменяет обновление; если текущая версия подписана,
  а новая — нет, в журнал пишется предупреждение.
- build.rs встраивает иконку, манифест и VERSIONINFO независимо: отсутствие
  `windres`/`rc.exe` больше не оставляет exe без версии.
- Подпись кода через SignPath подключена в workflow и включается добавлением
  секретов (см. `SECURITY.md`).

Функциональность не менялась: все возможности 2.9.1 на месте.

## 2.4.2

- Исправлен разбор `--dpi-desync-fake-tls=^!` в стратегиях Flowseal.
  В batch-файле `^!` — это экранированный `!` (встроенный fake TLS), но
  менеджер передавал winws.exe буквальный `^!`, из-за чего тот падал:
  `could not read ^!` (код 1).
- Теперь batch-экранирование `^` снимается перед запуском: `^!` → `!`,
  `^^` → `^`, `^&` → `&`.
- Это исправляет запуск `general (FAKE TLS AUTO)` и других стратегий
  с `^!`.

## 2.1.0

Полностью нативная версия на Rust: один `ZapretManager.exe` без .NET и WinForms.
Ветка `main` — актуальная Rust-версия; C#-версия больше не поддерживается.

### Новое

- **Автоподбор стратегии** на странице «Тест стратегий»: 40/120/250 вариантов
  desync-параметров вокруг выбранной базы; лучший сохраняется как `general (AUTO).bat`.
- **Отдельная страница «О программе»** с крупным логотипом, ссылками и поддержкой.
- **Тихий TG WS Proxy** из официальных исходников Flowseal + портативный Python
  (без окна и без иконки в трее).
