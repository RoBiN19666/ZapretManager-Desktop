# Zapret Manager 2.7.0

- После изменения списков, добавления доменов, игрового фильтра, активного
  фейка и режима IPSet работающее ускорение перезапускается автоматически:
  служба — через SCM, ручной запуск — через последнюю стратегию.
- Убраны сообщения «Перезапустите ускорение» там, где перезапуск теперь
  выполняется сам.
- Диагностика: если служба установлена, но не работает, появилась кнопка
  «Перезапустить службу».
- Меню трея полностью собственное: цвета темы, иконки, галочки состояния,
  разделители и подсветка строки.
- Включены исправления 2.6.2: тема применяется сразу при старте, иконка с
  картой, обновление менеджера в один клик, TCP timestamps-переключатель.
