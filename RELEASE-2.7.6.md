# Zapret Manager 2.7.6

- Лучшая стратегия теперь выбирается как в официальном тесте: сначала по
  общему числу прошедших целей, затем по числу рабочих сервисов (≥60 %).
- Раньше приоритет был обратным: стратегия с большим числом «рабочих групп»
  могла обогнать стратегию с большим числом реально прошедших целей.
- В подсказке теста объяснено, почему результат может отличаться от
  официального теста Flowseal: он делает 3 проверки на цель (HTTP/1.1,
  TLS 1.2, TLS 1.3), а менеджер — одну.
- Сортировка и отметка нескольких лучших сохранены.
