# Zapret Manager 2.4.0 — единая формулировка «ускорение»

- Все пользовательские тексты, README, docs и комментарии переведены на
  **«ускорение»**.
- Исправлены согласования: «ускорение запущено», «ускорение не запущено»,
  «остановка ускорения», «автолечение ускорения», «файлы ускорения».
- Убраны повторы вида «Ускорение (ускорение соединения…)».
- Технические идентификаторы `zapret`, `winws.exe`, имена служб, путей,
  файлов и ссылки на upstream оставлены без изменений: без них приложение
  не сможет управлять установкой.
- Название продукта `Zapret Manager` и логотип сохранены.

Проверки: 35 unit-тестов, `--selftest`, `--diag`.
