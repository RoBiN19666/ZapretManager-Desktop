# Rust-переписка: заметки о миграции

Ветка `rust-rewrite` — полная переписка C# WinForms-приложения на Rust.
C#-исходники остаются в ветке `main`; здесь их нет.

## Что перенесено 1:1

- `BatParser` — разбор `.bat`-стратегий: `set`-переменные, `%~dp0`, `%VAR%`, продолжение строк `^`,
  кавычки и сборка командной строки (`engine/bat.rs`, есть тесты).
- `GameFilterState` — `utils/game_filter.enabled`, токены `%GameFilterTCP%`/`%GameFilterUDP%`.
- `ZapretInstall` — поиск папки (настройки → служба → exe → подпапки → `C:\zapret`),
  версия из `LOCAL_VERSION`, `version.txt`, имени папки; естественная сортировка стратегий.
- `ZapretOps` — запуск `winws.exe` (raw-командная строка без переэкранирования), проверка
  «упал сразу/через пару секунд», `kill_winws` только для своей папки, служба, IPSet, фейки,
  hosts, кэш Discord, резервные копии.
- `ListChanges`/`ListAudit` — блок «мои добавления», `.baseline`, `.changes`, `.news`,
  применение после обновления, возврат удалённых, перенос в `*-user.txt`, вставка и чистка.
- `SiteDoctor` — этапы DNS/TCP/TLS/HTTP с теми же таймаутами, вердиктами и текстами;
  связанные домены (корень, `www/m/api/static/cdn/i`, хосты из HTML), запись в список и hosts.
- `SiteGuard` — журнал `Microsoft-Windows-DNS-Client/Operational`, фильтр браузеров,
  шум-лист, «не чаще раза в час», максимум 5 проверок за цикл, авто-добавление.
- `AppProbe` — процессы с окнами, та же программа и дочерние процессы, `netstat` для IP,
  наблюдение по шагам.
- `StrategyTester` — цели из `targets.txt`, базовая доступность без ускорения, глубокий тест 16 КБ,
  страницы-заглушки, TSV-отчёт, разбор официальных `test_results_*.txt`.
- `Diagnostics` — порядок проверок, тексты, исправления (`windivert`, `conflicts`, `tcp`,
  `discord`, `hosts`).
- `Update`/`SelfUpdate` — GitHub API, резервная копия, откат, сохранение пользовательских
  файлов, `--apply-update` без `cmd.exe`.
- `TgProxy` — поиск установки, `config.json`, `tg://`-ссылка, запуск/остановка, установка релиза.
- `Autostart` — задача `ZapretManager` с `ONLOGON`/`HIGHEST`, но через XML (нет проблем с кавычками).
- Конфиг `data\manager.ini` — тот же формат и те же ключи, совместим с C#-версией.

## Сознательные отличия

| Что | C# | Rust |
| --- | --- | --- |
| Служба | `sc.exe create/start/delete` | SCM API (`CreateServiceW`, `ControlService`, `DeleteService`) |
| HTTP | `HttpWebRequest`, TLS 1.2/1.3 | WinHTTP + системный TLS, `Accept-Encoding: identity` |
| DNS-журнал | `EventLogReader` | `wevtutil qe ... /f:xml` + разбор XML |
| Процессы | WMI (`Win32_Process`) | Toolhelp + `NtQueryInformationProcess(60)` |
| Автозапуск | `schtasks /Create /TR "..."` | XML-задача + `schtasks /Create /XML` |
| Поток UI | WinForms + `BeginInvoke` | egui immediate mode + канал сообщений из фоновых потоков |
| Тихий TG-прокси | портативный Python + pip | портативный Python 3.13 + pip (портировано в `TgSource`) |

## Сборка и подводные камни

- GNU-тулчейн (`x86_64-pc-windows-gnu`) не линкует проект, если в пути есть кириллица:
  задайте `CARGO_TARGET_DIR` в ASCII-папку (это делает `build.ps1`).
- Иконки и шрифты: PNG/ICO встроены в exe через `include_bytes!`; Segoe UI и Consolas
  читаются из `C:\Windows\Fonts` во время запуска (если файла нет — остаются шрифты egui).
- `build.rs` дополнительно встраивает `assets/zapret-manager.ico` и `VERSIONINFO`
  через `windres` (GNU) или `rc.exe` (MSVC).
- Скриншоты для документации: `--shot=<png> --shot-page=<key>` (egui screenshot API).

## Исправления 2.0.1–2.2.0

- HTTP 302: WinHTTP-политика редиректов исправлена на `ALWAYS`.
- Первый запуск: мастер открывается сам, показывает текущую папку, закрывается после
  выбора существующей папки или кнопкой «Готово».
- Тихий TG WS Proxy (исходники Flowseal + портативный Python) портирован.
- Одна карточка «Папка zapret» в настройках; выбор папки — проводником, без `service.bat`.
- Пустые `*-user.txt` разрешены: пустые аргументы не передаются в winws.
- Журнал DNS включается сам при стороже и проверке приложения.
- Тест стратегий: легенда, одна лучшая ★, автовыбор, без наложений/tofu-символов.
- Автоподбор: долгий перебор desync-параметров, сохранение `general (AUTO).bat`;
  расширенные `hostfakesplit`/`fake-tls-mod`/`badseq`, применение с проверкой и откатом.
- Аудит fake-файлов (blobs) с докачиванием из Flowseal/bol-van и CLI `--blobs-repair`.
- Резервная копия `.zmb`: настройки, пользовательские списки, targets и игровой фильтр.
- Оценка теста по сервисам (60%), поиск/избранное стратегий, автолечение ускорения
  и карточка ресурсов winws/TG WS Proxy.
- Окно «Доступны обновления» при старте со списком компонентов и версий;
  исправлено затемнение самого диалога.
- Светлая тема: светлый заголовок/рамка окна и светлые уведомления.
- Сторож сайтов читает DNS всех приложений и показывает перехваченные домены
  с кнопкой «Добавить найденные».
- Отдельная страница «О программе» с крупным логотипом, ссылками и поддержкой.
- Меню трея работает при скрытом окне (действия выполняются напрямую).
- CPU: опрос процессов в фоне, меньше нагрузок сторожа.

## Аудит и исправления (2.0.0)

Проведён полный проход по коду: `cargo clippy`, 26 unit-тестов, headless-самопроверка
(`--selftest`, 11 проверок), `--diag`, реальная проверка сайта и ручной просмотр всех страниц.

Исправлено по итогам аудита:

- `winws.exe`: сообщение про TCP timestamps больше не врёт — состояние фиксируется до включения.
- Установка службы: ожидание удаления старой службы и повторные попытки на коды 1072/1073.
- `service.bat` читается с автоопределением кодировки (CP1251), а не только UTF-8.
- «Запустить выбранную» в тесте стратегий находила не ту стратегию для имён с пробелами
  (`general (ALT10)`) — теперь берётся файл из строки отчёта.
- TG-прокси и состояние журнала DNS больше не опрашиваются каждый кадр (кэш 2–5 с) — меньше
  нагрузки на UI-поток.
- Дерево связанных адресов проверяется параллельно (6 потоков) вместо последовательных минут.
- Списки сохраняются атомарно (временный файл + переименование).
- Аргументы перезапуска с UAC корректно экранируются.
- Самообновление: поддержка `ZAPRET_GITHUB_TOKEN` и API-адресов ассетов для приватного репозитория,
  понятное сообщение при 404.
- Добавлены: самопроверка `--selftest`, тесты `.bat`-парсера/списков/конфига, запоминание размера
  окна и состояния «развёрнуто», тёмный заголовок окна, перехват паник в журнал.
