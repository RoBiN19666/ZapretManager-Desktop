# Zapret Manager 2.0.1–2.1.0 — исправления и автоподбор

Дата: 26.11.2026. Ветка: `rust-rewrite`; вторая ветка `main` — исходная C#-версия,
использовалась как эталон поведения.

## 2.1.0 — страница «О программе»

- Информация из «Инструментов» вынесена в отдельный раздел бокового меню.
- На странице показывается большой широкий логотип `assets/logo-wide.png` с названием,
  версия, описание компонентов, лицензия MIT, ссылки и кнопки поддержки.
- В «Инструментах» карточка «О программе» удалена.

## 2.1.0 — автоподбор стратегии

В «Тест стратегий» добавлена карточка «Автоподбор стратегии»:

- базовая стратегия выбирается из списка;
- глубина: 40 / 120 / 250 вариантов;
- `engine/autotune.rs` собирает значения desync-параметров из **всех** `.bat`
  (`--dpi-desync-repeats`, `split-pos`, `split-seqovl`, `fooling`, `ttl`, `autottl`,
  fake-файлы и т.п.) и генерирует замены в секциях базовой стратегии;
- варианты пишутся во временные `.bat` и прогоняются `tester::run_candidates`
  с базовой проверкой и восстановлением ускорение;
- лучший вариант сохраняется в корень zapret как `general (AUTO).bat`;
- кнопки «Запустить лучшую» и «Установить службой» используют этот файл;
- генерация покрыта unit-тестом: все варианты заново разбираются `bat::get_argv`.

## Исправления 2.0.1–2.0.2

- **HTTP 302.** WinHTTP настраивался на `REDIRECT_POLICY_NEVER` (0) вместо `ALWAYS` (2),
  поэтому не скачивались zapret и TG WS Proxy. Исправлено в `engine/http.rs`.
- **Мастер первого запуска.** Открывается сам при пустом `SetupDone`; лишний подкаталог
  `zapret\zapret` убран; при выборе существующей папки мастер закрывается и записывает
  `SetupDone`; показываются только реально нужные поля.
- **Тихий TG WS Proxy.** Портирован `TgSource`: исходники Flowseal, портативный Python 3.13.5,
  pip-зависимости, запуск через `pythonw.exe` без окна и трея. Добавлены `TgRunMode`,
  кнопка подготовки, `--tg-prepare`, `--tg-start`, `--tg-stop`.
- **Иконка.** `build.rs` встраивает `assets/zapret-manager.ico` и `VERSIONINFO`;
  дополнительно `WM_SETICON`/`GCLP_HICON` для панели задач.
- **Списки `*-user.txt`.** Создаются при старте/запуске/тесте. Пустые пользовательские
  списки теперь допустимы: `bat::get_argv` не передаёт пустые `--hostlist`/`--ipset-exclude`
  в winws, поэтому файл можно оставлять пустым.
- **Тест стратегий.** Убраны tofu-символы `✓/✗` (в Segoe UI их нет), текст в колонках
  обрезается, ошибка запуска не рисуется поверх «Итога», добавлена легенда, одна ★
  у лучшей и авто-выбор лучшей строки.
- **Одна папка zapret.** В «Настройках» карточка «Папка zapret»: указать папку, скачать
  с нуля, открыть, мастер. С «Обзора» и «Обновления» дублирующие кнопки убраны.
  Выбор папки — проводником, без поиска `service.bat`; можно выбрать и родителя.
- **Журнал DNS.** Включается автоматически при включённом стороже, при проверке
  приложения и `--app-watch`; кэш состояния исправлен.
- **Трей.** Действия меню выполняются напрямую и работают, когда окно скрыто;
  события трея обрабатываются в начале кадра.
- **CPU.** В стороже список процессов строился заново для каждого DNS-события
  (до 200 снимков Toolhelp за тик). Теперь один раз за тик, в XPath добавлен
  `EventRecordID > курсор`, интервал 10 с. Опрос состояния zapret/TG — в фоне.
