# Zapret Manager 2.6.0

## Иконка

- В качестве иконки приложения, окна и трея используется логотип без квадратной
  подложки — с картой и замком (`assets/lock.png`).
- Пересобраны `assets/zapret-manager.ico`, `assets/tray.ico` и `app-icon.png`.

## Обновления

- Уведомление «Доступны обновления» получило кнопку **«Обновить менеджер»** —
  запускает обновление сразу, без перехода на страницу и повторного подтверждения.
- На странице «Обновление» кнопка «Обновить менеджер» тоже применяет обновление
  сразу; лишнее окно подтверждения убрано.
- Во время скачивания кнопка блокируется, чтобы не запускать обновление дважды.

## TCP timestamps

- Кнопка теперь переключатель: «Включить TCP timestamps» / «Выключить TCP
  timestamps», состояние подтягивается из системы.
- Добавлена команда выключения timestamps.

## Светлая тема

- Светлый заголовок и рамка окна через DWM.
- Более светлая нейтральная палитра.
- Светлые всплывающие уведомления вместо тёмных.

## Сторож сайтов

- Читает DNS-события всех приложений, а не только браузеров.
- Показывает список перехваченных доменов.
- Кнопки «Добавить найденные» и «Очистить список».
- При включении сбрасывает DNS-кэш.
- Важно: если браузер использует DoH (Secure DNS), Windows не видит его
  DNS-запросы, и сторож их не получит. Это ограничение DNS-журнала Windows.
